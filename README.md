# Smart AI Recommendation System

## 🚀 Overview
A simple AI-powered web app that predicts performance based on study hours, attendance, and sleep. It gives instant results with actionable suggestions.

## ✨ Features
- Real-time prediction
- Clean, simple UI
- Easy to adapt to other domains (health, agriculture, business)

## 🛠️ Tech Stack
- Python (Flask)
- scikit-learn (Random Forest)
- HTML/CSS

## ▶️ Run Locally
```bash
pip install -r requirements.txt
cd model
python train_model.py
cd ..
python app.py
